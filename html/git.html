Git

Базовые команды терминала

  • git init — инициализация нового Git-репозитория в текущей папке.
  • git status — отображение состояния рабочего каталога и раздела проиндексированных файлов.
  • git add . — добавление всех изменений в рабочем каталоге в область подготовленных файлов (staging).
  • git commit -m "Сообщение" — фиксация (создание слепка) проиндексированных изменений с комментарием.
  • git log — отображение истории коммитов в репозитории.
